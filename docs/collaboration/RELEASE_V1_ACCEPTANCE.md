# HomePod Flow 正式 V1 独立验收门槛

日期：2026-11-06。状态：发布阻断清单/量化门槛首稿，未验收通过。本文以用户最新“完成正式功能及验收后交付”为准，优先于历史开发预览交付范围。总协调负责冻结版本范围，独立 QA 审核原始证据；不能以模型、离线测试、发送日志或听感分别替代尚缺的整机证据。

## 产品范围与发布原则

正式音源仅为 Mac 系统音频；提供同步与影院两种实际工作模式。设置只有一份共享布局，支持实际设备型号、音箱位置和听音位置；状态栏展示最后成功保存的布局。无文件播放、内置音效、演示设备或演示运行状态入口。首次授权、选择设备与必要的房间布局允许用户操作；正常启停不依赖终端、Python 环境或逐个音箱手工设置。

目标拓扑为前方 HomePod、后方两台独立 HomePod mini。两台设备可作为开发阶段检查，不能替代三台目标配置的正式验收。mini 原生立体声对只有实现且实测后才能显示为可用组合；未支持时明确说明拆分要求，不伪造左右独立控制。

release_architect 提醒原 PRD 还涉及原生立体声对、多声道与应用选择。这些项目不能由 QA 默认为已取消；总协调需对照原 PRD 与用户最新“系统音频”范围逐项给出实现/替代/范围决定并记录依据。未明确处置的历史承诺仍为发布缺口，不能因本表聚焦主链路而消失。

所有 P0 门槛须有可复核证据；P1 为用户可见承诺的完整性门槛，也须完成后发布。可以调整实现方案，但不能用隐藏错误、保存无效偏好、改名或删除本轮用户要求的功能来代替验收。实际声学测试须由总协调按用户已授权范围安排；本文不授权 QA 自行录音、采集或出声。

## 同步与稳定性量化方法

以下是 QA 建议冻结值，需 release_architect/总协调确认后作为正式版本指标；未确认前不得写“已达到”。采用同一录制时钟分析，记录设备位置、采样率、测量方法及误差；传播延迟按测量距离校正，无法可靠分离各路声音时该录音不可用于量化结论。

- 三台任意两台校正后相对偏差 p95≤10ms、最大≤20ms；同一对设备在 30 分钟内相对偏差变化≤5ms。
- 30 分钟正常内容连续会话无非预期重启、队列溢出、音频缺口；日志资源峰值不超过配置预算。进程预热后 RSS 不持续随音频时长线性增长，比较第5/15/30分钟并解释显著增长；初稿门槛为5→30分钟增幅≤50MiB且末段不持续上升。
- 60秒及30分钟均记录输入/输出帧、共同 presentation/RTP 计划、消费累计、队列峰值、清理结果；操作系统网络延迟不是声学误差证据。
- 影院若设计额外声道延迟，先冻结预期延迟矩阵；验收比较“实测减设计值”的残差，不把刻意延迟误判为失步，也不能用未记录的偏移解释失败。

## 与 release_architect 对齐的实现验收约束

影院最低方案为独立可移植 DSP 层，对实际 stereo 输入按保存布局作 M/S 矩阵推导。UI 明确标为“立体声·空间分配”；前方保留 L/R，后侧为衰减差分加低电平原 L/R，单声道内容不能消失。冻结矩阵后，验证每行系数绝对值之和≤1、有限输入不产生 NaN/Inf、mono/纯左/纯右/反相输入均符合矩阵；不得每路另加未声明延迟。影院真实不同分配与以上边界均是验收条件，新增库不意味着核心 v1 ABI 可以改变。

运行中 gain/音量采用共同媒体帧边界的20ms平滑，验收最终值、轨间一致性与无非预期不连续；不能先后更新各路造成瞬间分裂。全局 offset 只能延后音频，或减少明确预留的缓存；负值若相对缓存基准表示，应显示真实可用下限与实际含义，不能用 ±3500ms 视觉范围伪造能力。任意应用的视频提前/延后控制未实现时不得宣称已支持任意负向校正。

短暂断连的最低恢复方案为全组停止、清理、创建新 epoch 后共同恢复；系统源暂停/恢复或 seek 不得任意重放旧缓存。若实际实现需要用户点击重新开始，须先由产品范围决定是否满足“尽量少的人工参与”，不能测试后才将自动恢复的缺口改写为通过。

## 当前结论与证据分级

当前状态为正式版未通过，不能交付为“已验收正式版”。既有原生核心、跨语言、受管 worker、平台及 UI 状态检查可复用；根协调转述最新平台27项和 live17项候选均通过，原始日志待回传独立核对。

真实 host 已获得持续转换帧但样本全零；最新 TCC 责任链为 com.homepodflow.mac、authValue0，用户系统列表尚无 App。它们证明仍有授权/有效音源阻断，不能由签名成功、ready、帧数增长解除 V1-01/02。下一优先级是固定安装与正常桌面权限闭环→有效有声采集→三路/影院/运行中控制→量化长时/故障恢复→正式安装及 UI 端到端复核。

每项证据必须标明：纯函数/模拟、真实库离线、真实捕获、实际音箱出声、声学量化中的哪一级，以及输入、命令/用户动作、软件哈希、时间、原始结果和未验证项。发布前由总协调逐项填入报告链接并由独立 QA 签署；无记录视为未验证。
