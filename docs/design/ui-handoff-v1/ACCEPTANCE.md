## 结构与交互（P0）

- [ ] 菜单栏从上到下：标题/开关 → 双模式 → 缩略图 → 音量 → 延迟 → 设置
- [ ] 没有第三个模式、额外关闭行、复杂主控制台
- [ ] 「设置」打开独立 Window，而不是弹窗内子视图
- [ ] 默认设置页是空间布局
- [ ] 音量范围 0~100 且 UI 同步
- [ ] 延迟范围 **-3500 到 +3500 ms**，边界与数值编辑可靠
- [ ] 影院模式可编辑布局，同步模式只读
- [ ] 房间缩略图与编辑器使用同一布局数据，拖动后刷新
- [ ] 设备只显示名称+位置（未发现时明确 Mock）
- [ ] 听音位置图标有独立可辨认的左右耳朵
- [ ] 俯视 HomePod:mini 直径比约 1.45:1
- [ ] mini 立体声对显示两处空间位置但正确识别为一个双声道输出组

## 视觉一致性（P1）

- [ ] 弹窗宽度、内容密度与参考接近，完整显示不用滚动
- [ ] 双模式等宽，选中态蓝色，系统样式开关
- [ ] 真实可交互的布局小图和大图内容、方向一致

## 测试条件与结果

- [ ] macOS Xcode 工程可以 clean build，无错误
- [ ] 点击设置会弹出/聚焦唯一设置窗口，重复点击不会重复打开
- [ ] 持久化模式、音量、延迟、布局，重启后恢复（注意未授权/设备失联）
- [ ] 运行时截图真实出自编译后的 App，而非效果图再次生成

- [ ] Agent 逐页用截图对比参考，报告偏差、修复迭代、剩余差异

## 如何验证误差（建议）

首次运行截图按对应窗口裁切到相同参考边界，视觉比较优先检查：区域顺序、信息密度、设备相对位置、坐标比例、间距、字体层次、边框与亮度。可叠图观察明显偏移，但 AI 生成效果图不是像素级原型，**不要因微小纹理或系统材质差异牺牲交互正确性**。
