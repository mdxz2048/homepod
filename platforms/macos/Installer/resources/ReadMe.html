HomePod Flow 安装说明

安装内容

  • /Applications/HomePod Flow.app
  • /Library/Audio/Plug-Ins/HAL/HomePodFlowAudioFamily.driver（显示名：HomePod Flow Audio）
  • /Library/Application Support/HomePodFlow：安装清单、重启状态和只读探针

安装后

  1. 重新启动 Mac，加载新版虚拟声卡驱动。
  2. 打开 HomePod Flow。
  3. 在“设置 → 空间布局”顶部确认“音频组件已就绪”。
  4. 使用 App 的“系统声音”开关，等待默认输出切换确认后播放。

安装后同一次系统启动期间，App 会显示需要重启，并暂停使用旧的内存驱动。下载更新前会校验版本信息签名和安装包完整性。

没有包含的内容

这个安装包已经包含 App、虚拟声卡、冻结的 Python worker、runtime 项目、core dylib 和 hflctl，不需要 Homebrew Python 或本机 runtime.json。App 已支持从项目网站检查并一键更新。正式 Developer ID 签名/公证另行处理；当前构建不能据此宣称已公证。

卸载

打开安装镜像，双击“Uninstall HomePod Flow.command”。它只删除上面的 HomePod Flow 文件，不会删除其他厂商的 HAL 组件。
