HomePod Flow 安装说明

安装内容

  • /Applications/HomePod Flow.app
  • /Library/Audio/Plug-Ins/HAL/HomePodFlowAudioFamily.driver（显示名：HomePod Flow Audio）
  • /Library/Application Support/HomePodFlow：安装清单、备份和只读探针

安装后

  1. 打开 HomePod Flow。
  2. 在“设置 → 空间布局”顶部确认“音频组件已就绪”。
  3. 在播放器或“系统设置 → 声音”中选择 HomePod Flow Audio。

如果组件显示“等待加载”，先点“重新检查”；仍不出现时重启 Mac。安装程序会尝试自动重载系统音频服务，但 macOS 26 的 SIP 可能拒绝重启 coreaudiod（Operation not permitted），此时必须重启 Mac。

没有包含的内容

这个安装包已经包含 App、虚拟声卡、冻结的 Python worker、runtime 项目、core dylib 和 hflctl，不需要 Homebrew Python 或本机 runtime.json。正式 Developer ID 签名/公证和自动更新仍按项目发布流程单独提供；当前构建不能据此宣称已公证。

卸载

打开安装镜像，双击“Uninstall HomePod Flow.command”。它只删除上面的 HomePod Flow 文件，不会删除其他厂商的 HAL 组件。
