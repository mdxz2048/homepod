安装 HomePod Flow

这个安装包会把 HomePod Flow App 和 HomePod Flow Audio 虚拟声卡 一起安装到本机。

App 内已包含冻结的 Python 音频服务、runtime 项目、核心库和延迟 helper，不需要另外安装 Python 或配置路径。

安装程序需要管理员权限，并会做两件事：

  • 备份并替换旧的 HomePod Flow 音频组件；
  • 重新加载系统音频服务，让新声卡出现在“声音”设置和播放器的输出列表中。

重新加载音频服务时，正在播放的声音可能短暂中断。安装程序不会把虚拟声卡设为默认输出，也不会删除你的音箱布局或偏好设置。

macOS 可能因 System Integrity Protection 拒绝重启 coreaudiod。如果安装完成后没有看到 HomePod Flow Audio，请重启 Mac。
